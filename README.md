### André Ratzenberger

Software and AI Solution Architect at [white duck](https://whiteduck.de/en/), Rosenheim / Munich.

I ship software through coding agents. People own the specification, the checks and the
acceptance, and the agents write the code. Rules belong in code, not in prompts.

**What I build**

- [**Flock**](https://github.com/whiteducksoftware/flock): a contract-based agent system in
  Python. Agents declare typed inputs and outputs and coordinate through a blackboard instead of
  hand-wired graphs. Ships an adapter for Microsoft Foundry Hosted Agents.
- [**Tare**](https://github.com/a-ratz/tare): proves that your coding agent starts without your
  personal setup before you measure it. Works with Codex, Claude Code, Pi and Antigravity.
- [**Dojo**](https://github.com/a-ratz/dojo): creates and evaluates agent skills by comparing
  baseline and candidate runs.
- [**Atlas**](https://github.com/a-ratz/atlas): grow a knowledge vault by talking to your agents,
  and read it like a book. [Live demo](https://a-ratz.github.io/atlas/).
- [**tendril**](https://github.com/a-ratz/tendril): an experiment with the Codex SDK. Agent
  threads are application state on a graph, and every change passes proof checks and human
  approval.
- [**wd-lecture-agents-2026**](https://github.com/a-ratz/wd-lecture-agents-2026): a four-hour
  hands-on workshop on Codex, Claude Code and GitHub Copilot (German).
